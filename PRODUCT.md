## Platform

web

## Stack
React 19, Vite 8, Tailwind CSS v4, shadcn/ui, Bun runtime

## Users
Developers and end users interacting with modern web applications and SaaS platforms.

## Product Purpose
Interactive web application and SaaS platform delivering fast, responsive UI components, live state management, and high-craft user experience.

## Positioning
High-performance React application powered by Bun and Vite, leveraging Tailwind CSS v4 design tokens and shadcn/ui primitives.

## Operating Context
Web browsers across desktop and mobile devices with fluid layout adaptations and seamless dark/light mode toggling.

## Capabilities and Constraints
- Built on Vite, React 19, and Bun
- Styled with Tailwind CSS v4 and shadcn/ui component system
- Full dark mode and light mode theme support
- Responsive tabs, dialogs, badges, cards, and interactive forms

## Brand Commitments
- High-craft, modern visual design with vibrant accents and glassmorphism elements
- Clean typography, balanced spacing, and subtle micro-interactions
